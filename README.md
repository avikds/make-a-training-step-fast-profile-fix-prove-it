# make-a-training-step-fast-profile-fix-prove-it
A small transformer trains on 8 GPUs and each step takes 155 ms. Profile it the way a performance engineer does: cost every kernel with the roofline, read the trace to find what the GPU is waiting for, and measure with warmup and medians instead of single runs. Then fix what the profile shows, one thing at a time: data-loader workers, bf16,…
